## ▶️ How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open PowerShell or a terminal in the project folder.
4. Run the required Python file using the command shown in its project section.

On Windows, use the `py` command. On systems configured differently, you may need to use `python` or `python3`.
